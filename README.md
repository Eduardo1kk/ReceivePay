# ReceivePay


Projeto que simula uma plataforma de pagamentos utilizando linguagem Java no Backend. Projeto acadêmico.



## O que se espera?

Este projeto deverá conter software responsivo e simular os métodos de pagamentos em pix e cartão, assim como um banco ou alguma instituição financeira. Será possível ver extrato bancário. (simulação)

## Tecnologias em uso:

## Frontend:
- React + Typescript
- CSS3

## Backend:
- Java JDK 8

## Banco de Dados:
- MySQL
